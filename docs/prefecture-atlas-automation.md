# 記事で塗る日本地図の定期収集

対象Site: appgprj_6b060907928081918668c39b5a473203
GitHub: komakikosuke/shirokuma-bungeibu
更新対象ブランチ: feature/prefecture-atlas

収集本体は scripts/sync_prefecture_atlas.py。GitHub Actionsの Validate and sync prefecture creator atlas が実行する。クラウドタスクは3時間ごとに起動要求だけを保存し、記事取得とJSON更新はActionsが行う。タスクの認証は接続済みGitHubを使用し、トークンをファイルやプロンプトに保存しない。

## 1回の実行

1. GitHubからこの手順と、対象ブランチの data/prefecture-atlas-request.json の最新内容・blob SHAを読む。同じブランチで収集中なら重ねて起動せず、進行中の実行を確認する。
2. GitHubのupdate_fileで同じブランチの要求JSONを更新する。versionは1、requestedAtは実行時の現在UTC日時（ISO 8601、秒付き、末尾Z）。新規の現在時刻を使い、直前に読んだblob SHAをshaとして渡す。コミットメッセージは Request prefecture atlas collection。競合した場合は最新内容を読み直して1回だけ再試行する。
3. このpushで .github/workflows/sync-prefecture-atlas.yml が起動する。GitHub Actionsの実行一覧から要求コミットに対応するpush実行を確認する。実行中のときは完了を待つ。承認要求や接続要求が出た場合は回避せず、処理できていないことを報告する。
4. 成功後、同じブランチの data/prefecture-atlas.json を読み戻す。version=1、sampleフラグなし、tag=記事で塗る日本地図、generatedAtが今回の要求時刻以降、sync.status=okであることを確認する。0記事でも成功。記事ごとの省略名は都道府県コードへ正規化される。
5. Siteはこの最新JSONを直接読むため、通常の収集時に再公開はしない。既存ホームへの入口、main、共有設定、収集ロジックは変更しない。正常終了の通知は不要。収集失敗・一部失敗・読み戻し失敗だけを具体的な原因とともに報告する。

## 掲載条件

公開記事の登録ハッシュタグに #記事で塗る日本地図 と、47都道府県のいずれかのタグが両方必要。都・府・県は省略可（東京・大阪・京都・神奈川など）。北海道は北海道。派生タグや本文だけの記載は対象外。複数の県のタグはそれぞれに掲載する。出身地・ジャンル・文字数・有料かどうかは問わない。

## 障害時

収集の全体失敗では前回データを保持する。記事単位の一時エラーでも前回確認済みレコードを保持する。削除・非公開化・参加タグの削除を確認した記事は掲載から外す。

## 地図の変化の記録・再生

2026年12月1日0:00（日本時間）以降の収集が正常終了したとき、掲載JSONの `history` に反映日時 `at`（UTC）と47都道府県の件数 `counts` を追記する。初回は開始時の白地図も保存する。記事の投稿日から過去の履歴を推定しない。同じ記事は県ごとに重複を除く。記事削除による件数減少も記録する。全体失敗・部分失敗では既存履歴を保持し、新しいスナップショットを追加しない。掲載データと履歴は同じJSONへ原子的に保存するため、既存のActionsの保存対象で一緒に更新される。

「これまでの変化を見る」は地図ツールバーの補助機能。開いたときに最初の白地図から最新へ約12秒で再生する。操作ボタンは置かず、日時スライダーに触れたときに停止する。再生し直すときは操作欄を閉じて開き直す。記事一覧は最新のまま。県選択や一覧表示に移ると履歴再生を終了する。動きを減らす設定では自動再生しない。記録開始前は案内のみを表示する。

正常終了後は既存の掲載JSON確認に加え、12月1日以降なら `history` の最終 `at` が `generatedAt` と一致し、各スナップショットに47都道府県の非負整数の件数があることを確認する。過去の履歴を削除・再生成しない。

公開用画面にはデバッグの入口・バナー・URL切り替え・仮データ生成を含めない。`?debug=history` や `?debug=komaki` が付いていても実際の掲載データだけを表示する。掲載JSONの `sample: true` とプレビュー用途のデータは読み込みエラーとして拒否する。
